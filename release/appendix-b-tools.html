Phụ lục B: Công cụ & tài nguyên

Tổng hợp các công cụ và tài nguyên được dùng hoặc nhắc đến trong sách, nhóm theo chức năng. Các ví dụ mã giả định Spring Boot 3.x (Jakarta EE 10+, Java 17+); với Spring Boot 2.x, namespace javax.* thay cho jakarta.* và một số API cấu hình khác. Phiên bản cụ thể của từng công cụ thay đổi theo thời gian; xem trang chính thức của công cụ để có thông tin mới nhất.
