Redis Rate Limiter trong KBLab: Gateway sử dụng thuật toán Token Bucket. Hệ thống liên tục "nhỏ giọt" tokens vào xô (ví dụ: 2 request/giây). Nếu user gửi requests liên tục (burst), họ sẽ tiêu thụ sạch token trong xô (max 10). Khi xô rỗng, các requests tiếp theo sẽ bị từ chối với mã lỗi 429 Too Many Requests cho đến khi xô có token mới.
