Phase 0: Hệ thống nguyên khối. Client kết nối trực tiếp đến Monolith (hoặc qua một proxy đơn giản). Tất cả module (Auth, Core, Judge) nằm chung một codebase và chung một database. Bất kỳ thay đổi nào cũng yêu cầu deploy lại toàn bộ.
🔍 Từ Sách (Chương 10): "Never do a big bang rewrite. Strangle the monolith incrementally — each step delivers value, each step is reversible. API Gateway đóng vai trò tự nhiên làm seam cho Strangler Fig... Dùng route-based strategy: Gateway route paths khác nhau đến monolith/services."
