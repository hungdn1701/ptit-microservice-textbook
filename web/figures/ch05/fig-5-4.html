Routing rules — Exchange type: topic
build.frontend → queue build-frontend-queue → Worker 1 executes frontend build job
build.backend → queue build-backend-queue → Worker 2 executes backend build job
deploy.# → queue deploy-queue → Deployment Agent executes rollout to environment
Each queue only receives jobs matching the routing key — Workers scale independently based on job load.
