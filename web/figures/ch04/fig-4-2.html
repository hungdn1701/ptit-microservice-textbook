Feign Proxy Pipeline
1. Tìm kiếm (Eureka)
Lấy IP của instance khỏe
2. Dựng HTTP Request
Method, URL, gắn JWT
3. Xử lý phản hồi / Lỗi
Decode JSON + Fallback
Feign Interface
Khai báo @FeignClient
Sinh proxy
Gọi mạng (HTTP)
Dịch vụ đích (Target)
(Ví dụ: Judge Service)
@FeignClient(name = "judge-service")
public interface JudgeClient {
@PostMapping("/api/judge/execute")
JudgeResult execute(@RequestBody SubmitRequest req);
}
