🔍 Từ Sách (Chương 4): "Khi circuit ở trạng thái Open, mọi request được reject ngay lập tức — không gửi tới service downstream. Điều này bảo vệ cả caller (không block threads chờ timeout) và callee (không bị overwhelm khi đang recovery)... Trong KBLab, Core Service gọi Judge Service qua OpenFeign. Nếu Judge sập, ta trả về Fallback message thay vì để toàn bộ LMS bị treo theo."
JudgeCallService.java (Resilience4j Implementation) 
// Core Service — gọi Judge với đầy đủ resilience patterns
@CircuitBreaker(name = "judge", fallbackMethod = "judgeFallback")
@Retry(name = "judge")
@TimeLimiter(name = "judge")
public CompletableFuture<JudgeResult> executeSQL(JudgeRequest request) {
    return CompletableFuture.supplyAsync(() -> judgeFeignClient.execute(request));
}

// Fallback khi circuit OPEN (Ngắt Mạch)
private CompletableFuture<JudgeResult> judgeFallback(JudgeRequest req, Throwable t) {
    log.warn("Judge unavailable, executing fallback");
    return CompletableFuture.completedFuture(
        JudgeResult.pending("Sandbox đang bận, bài sẽ được chấm khi sẵn sàng")
    );
}
