Benefits of asynchronous architecture
1 Non-blocking: Core Service is not blocked by slow judging
2 Extensibility: Adding new consumers (Analytics, Replay) without modifying core code
3 Fault Tolerance: Judge down → messages wait in Kafka, no loss, reprocessed upon recovery
4 Independent Scaling: Scale Judge pods according to contest load
