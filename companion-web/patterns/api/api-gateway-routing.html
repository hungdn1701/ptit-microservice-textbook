🔍 Từ Sách (Chương 8): "Cross-cutting concerns tại Gateway: Thay vì mỗi service tự validate JWT, tự xử lý CORS... Gateway tập trung xử lý tại một điểm duy nhất. Gateway giải mã JWT, sau đó truyền thông tin user xuống downstream service thông qua HTTP Headers (X-User-Id). Spring Cloud Gateway dùng StripPrefix=2 để biến /api/core/questions thành /questions trước khi forward tới Core Service."
