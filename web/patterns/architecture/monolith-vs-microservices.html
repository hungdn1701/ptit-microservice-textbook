So sánh thời gian deploy khi chỉ cần cập nhật module Judge

Monolith — rebuild & deploy toàn bộ app
Microservices — deploy Judge only
KBLab LMS — Context Hệ thống KBLab bắt đầu là một monolith Spring Boot duy nhất. Khi module Judge cần scale riêng vào mùa thi (xử lý SQL submission đồng thời), team buộc phải tách kblab-judge ra thành microservice độc lập — đây là tín hiệu tự nhiên cho microservices decomposition.
