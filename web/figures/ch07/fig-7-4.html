1. Đọc/Ghi Cache
2. Đọc DB (nếu Miss)
Đặc điểm
- App tự làm việc với cả Cache & DB.
- Luồng Miss: App đọc DB → App ghi Cache.
- Dễ triển khai, phổ biến nhất (Redis).
2. Read/Write-Through
App
Cache Layer
DB

Đặc điểm
- App chỉ biết đến Cache Layer.
- Cache tự động đọc/ghi đồng bộ (Sync) với DB.
- Code App cực sạch (Transparent to app).

App
Cache Layer
DB

Ghi gộp (Async/Batch)
Đặc điểm
- App ghi vào Cache là trả về ngay lập tức.
- Cache xả dữ liệu xuống DB định kỳ (Eventual).
- Throughput siêu cao, có rủi ro mất data.
