# Archive: Manuscript v1.0.2

Thư mục này chứa toàn bộ nội dung sách dưới dạng Markdown — đây là **archive công khai của v1.0.2**, không phải nguồn biên soạn active.

**Mục đích**: Tham chiếu lịch sử, revise lại nội dung nếu phát hiện sai sót, so sánh với `.typ` files hiện tại.

**Lưu ý quan trọng**: Từ luồng hậu release v1.0.2 trở đi, nội dung được viết và duy trì **trực tiếp** trong:
```
references/internal/typst/chapters/*.typ
```

Các file `.md` ở đây **không còn được sử dụng trong build pipeline**. Mọi thay đổi nội dung phải thực hiện trong `.typ` files.

> Có thể xóa thư mục `manuscript/` sau khi sách đã ổn định ở v1.0.3+.
